# Short demonstration route

Use **http://127.0.0.1:8000/**, not the isolated test server on 8001.
No deck or video has been generated by the assistant; you are recording it.

1. Show the saved repository review and expand E1. Explain that static
   read_csv calls establish limited code observations, not authorship/mastery.
2. In Opportunities, select **Import: support the Trakt CSV export** and
   press **Start connected practice**. Its requirements were assessed through
   Nightshift; the exact source passages and gaps remain available above.
3. Show the flow ID, issue ID and Zetaris joined records. This uses the selected
   review's evidence and issue as query-local inputs in the real Zetaris engine;
   they are not newly registered persistent tables.
4. Expand **Demonstrate feedback with clearly labeled AI references**.
   Press **Try reference that loses leading zeros**. Show the failed identifier
   check and the recommendation to revise the output.
5. Press **Try correct AI reference**. Show the passing checks and H-MEM
   assistance history. The recommendation requests independent evidence and
   automatically creates a follow-up with different IDs and ratings.
6. Show the private draft for **the same issue**. It describes the actual
   checked output and AI assistance, and does not claim implementation readiness.
   Sending is disabled. The three-attempt budget does not reset.

The primary recording flow was left at **0/3 attempts** after isolated tests.
The two example buttons use two attempts. You may show the follow-up without
submitting it. If you run the correct reference on the follow-up too, the
third attempt triggers stop-for-user-review; no fourth attempt is allowed.
Do not repeatedly click the same action while it is working.

Say clearly: practice grades submitted JSON output on fixed CSV inputs. It
does not execute uploaded Python, prove authorship, or solve the Trakt issue.
Nightshift provider timeouts are visible for one other candidate; the working
flow uses a successfully assessed candidate. The older O1 example is collapsed
and remains a separate historical demonstration.

If the server needs restarting: Ctrl+C in its terminal, then `python api_server.py`.
Refresh the browser after a restart. Start Docker/Nightshift for live sponsor
checks; the recorded review can still be inspected when those are unavailable.
